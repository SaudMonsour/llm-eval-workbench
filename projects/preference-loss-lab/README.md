# مختبر خسارة التفضيلات

دراسة لتحسين سياسة تفضيل صغيرة بالمقارنة بين التحديث المباشر للتفضيلات والتدريب الإشرافي والسياسة المرجعية المجمّدة.

البيانات اصطناعية بسياقات من ست خصائص وثلاثة اختيارات، ومرجع خطي ثابت يحدد التفضيل بين اختيارين. تضم 600 زوج تدريب و200 للتحقق و200 للاختبار؛ لا تمثل استجابات نموذج لغوي أو تفضيلات بشرية.

تستخدم الطرق القابلة للتدريب انحدارًا متدرجًا كامل الدفعة بمعدل 0.2 لمدة 400 خطوة. اختيرت نقطة الحفظ داخل كل طريقة على خسارتها الخاصة. اختار التدريب الإشرافي الخطوة 222، وجميع تجارب DPO الخطوة الأخيرة؛ لذلك لم تثبت التجارب تقارب DPO بعد.

لا تُقارن قيم الخسارة مباشرةً بين معاملات بيتا المختلفة أو مع التدريب الإشرافي. يقيس KL تغير توزيع الاختيارات كاملًا عن المرجع؛ الدقة وحدها لا تصف هذا التغير.

اجتازت ثمانية فحوص الخسارة المرجعية والتدرجات وثبات التحويل وتطبيع الاحتمالات ورفض بيتا غير الصالحة. لكل زوج في الاختبار سجل هامش وصحة، مع حفظ الأوزان والمنحنيات. لا توجد دعوى لتحسين محاذاة نموذج لغوي حقيقي أو ضمان أمني.

## النتائج المسجّلة

الأرقام التالية من التنفيذ المحفوظ لهذه النسخة؛ لم تُعَد التجارب أثناء تعريب التوثيق.

### التقييم المحفوظ: 200 زوج تفضيل

| الطريقة | ترتيب أزواج التفضيل الصحيح | الأخطاء | متوسط KL عن المرجع |
| :--- | ---: | ---: | ---: |
| السياسة المرجعية المجمّدة | 45.5% | 109 | 0.0000 |
| SFT | 95.5% | 9 | 0.2242 |
| DPO بمعامل بيتا 0.1 | 93.5% | 13 | 0.1389 |
| DPO بمعامل بيتا 0.5 | 95.5% | 9 | 0.5151 |
| DPO بمعامل بيتا 1 | 96.5% | 7 | 0.5261 |
